VisualVault

or vv (vivi) for short

An interactive terminal browser for HashiCorp Vault. The parts of the web UI you actually use, without the browser.

Download latest Read the docs View on GitHub

Features

Lazy tree

Opening it lists the mounts and nothing else. A path is read the first time you expand it, so a Vault with ten thousand secrets starts instantly.

Masked by default

Values render as dots until you press r, and the reveal is dropped the moment you navigate away. y copies without ever drawing it.

In-panel editing

Edit fields where you read them, in a form that shows the JSON it will write. A pasted certificate keeps its lines, and a field keeps the type the server gave it.

Check-and-set on save

The save carries the version you opened. If someone wrote in the meantime the write is rejected, your edit is kept, and you choose what happens next.

Full version history

Read any version, roll back, soft-delete, undelete, destroy, or delete the metadata, with confirmation that scales to the damage.

Diff two versions

Mark two versions with space and d compares them, masked, so you can see what changed without reading the values.

Auditing

Policies and auth methods, read-only, with a jump from a role straight to the policy it grants. Every secret says what your token may do there.

Read-only mode

--read-only refuses every write; --read-only=prod refuses them only where the badge says PROD. Nothing reaches the server.

Honest about denial

A path your token cannot list is shown as locked, never hidden. A browser that quietly omits what you cannot see is worthless for an audit.

Knows where it is

The header badges the environment, names the server version, warns on a standby or sealed node, and counts the token down, loudly under fifteen minutes.

KV v1 and v2

v1 mounts degrade the interface instead of breaking it: no history, no rollback, and a delete that warns it cannot be undone.

A command line too

: lists what can run right now with the keystroke beside each entry, so the slow path teaches the fast one.

56 themes

The palette follows your terminal background by default. --theme replaces it with a fixed one, and --list-themes shows them.

Self-update

vivi self-update installs the latest release, checked against the checksum published with it. No checksum, no install.

Installation

go install github.com/lucasassuncao/vivi@latest
# 1. Download the binary for your platform from the releases page
#    https://github.com/lucasassuncao/vivi/releases

# 2. Put it on your PATH, then keep it current with:
vivi self-update
git clone https://github.com/lucasassuncao/vivi.git
cd vivi
make build   # goreleaser, current platform
make install # go install

Quick start

vivi authenticates exactly like the vault CLI, from the environment. It has no configuration file of its own.

export VAULT_ADDR=https://vault.corp:8200
export VAULT_TOKEN=...          # or: vault login
export VAULT_NAMESPACE=...      # optional, Vault Enterprise

vivi                            # browse
vivi --read-only=prod           # refuse writes where the badge says PROD

The token needs read on sys/mounts on top of the paths you want to browse: that is what tells a KV v1 mount from a v2 one.

path "sys/mounts" {
  capabilities = ["read"]
}

Try it without a Vault

The repository ships a throwaway Vault, seeded with both KV versions, a deep tree, a secret whose history includes a deleted and a destroyed version, policies, auth methods with roles, and a subtree a limited token cannot read.

make vault-up    # docker compose up, then seed it
make vault-down  # stop it and discard the data

Keys

Key Does
↑ ↓ → ←Move, go further in, come back out
/Fuzzy filter over what is already loaded
rReveal, without copying
yCopy, without showing it
e · aEdit a secret · create one
vVersion list: diff, rollback, undelete, destroy
dDelete the version on screen (in the version list, d diffs instead)
iToken information, where it can also be renewed
:The command line, listing what can run right now
?The contextual key panel

Every key, per pane, is in the keys reference.

Commands

Command Description
viviOpens the browser
vivi --read-onlyRefuses every write, wherever this points
vivi --read-only=prodRefuses them only where the badge says PROD
vivi --theme <name>Renders with a named colour theme
vivi --list-themesLists the available themes
vivi --versionPrints the version
vivi self-updateInstalls the latest release from GitHub, checksum-verified
vivi self-update --listShows the available releases
vivi self-update --version <tag>Installs one release by tag instead of the latest
vivi self-update --prereleaseIncludes rc/beta/alpha releases
vivi self-update --allow-unverifiedInstalls a release that publishes no checksum
